Gestión de solicitudes de recursos

Taller No. 2 Jakarta EE + Tier de Negocio. API REST publicada en rest/solicitudes:

  • POST rest/solicitudes registrar una solicitud
  • GET rest/solicitudes consultar todas
  • GET rest/solicitudes/{id} buscar por identificador
  • GET rest/solicitudes/pendientes consultar pendientes
  • PUT rest/solicitudes/{id}/atender atender una solicitud
